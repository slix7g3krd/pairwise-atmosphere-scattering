# pairwise-atmosphere-scattering

从海边一路开到山顶，天空从蓝变灰再变黑，太阳落山时地平线出现一条硬边，云层后面透出一块方形亮斑：大气散射 LUT 按海拔取密度，但密度表在山顶被钳到同一个值，天空整片发灰；瑞利和米氏散射的 scale height 用世界单位，行星半径一改参数就失效；太阳盘和天空 LUT 分开积分，日落时太阳边缘与地平线亮度不连续；透射率 LUT 只按天顶角采样，视线接近地平线时出现条带；多次散射近似系数固定，厚云天气天空过亮；空中透视按相机高度算，飞行器升空后远景被错误染成雾色；行星阴影只查一个方向，日食时天空仍全亮；云影贴图没参与大气积分，云后透出方形 LUT 块；HDR 天空和曝光补偿各算一次，转视角时亮度跳变；相机进入水下或太空后介质参数没切换，整屏变黑；时间流逝时 LUT 每帧重建但异步队列没同步，太阳位置和天空错一帧；天气系统换预设时只换颜色，散射系数没换，彩虹和晚霞同时出现。render/sky_atmosphere.py 是核心，tests/test_sky_atmosphere.py 15个红。要修的是：海拔密度；物理 scale height；日月盘一致；透射率采样；多次散射；空中透视；行星阴影；云影注入；曝光唯一；介质切换；LUT 同步；天气系数。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
